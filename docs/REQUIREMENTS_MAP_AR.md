# تتبع المتطلبات إلى ملفات التنفيذ

| المتطلب SRS v1.3 | مكانه في المشروع | الحالة |
|---|---|---|
| FR-13 / NFR-03 (لغة عربية RTL) | `mobile/lib/main.dart` والواجهات | تأسيسي، يحتاج اختبار أجهزة |
| FR-19, FR-20, FR-22, FR-124 (رمز مجهّل وموافقة وعمر فقط) | `models/student.dart`, `features/students_screen.dart` | إدخال محلي تجريبي، بلا مصادقة |
| FR-102–110 (بطاقات التقييم الست) | `data/assessment_templates.dart` | البنود موجودة وتحتاج مراجعة المختصة |
| FR-103 (فئات عمرية 6–8 / 9–12) | `recommendedAgeGroup()` وشاشة البدء | تجريبي |
| FR-111 (إجابة مرجعية للمختصة) | `AssessmentScreen` / ExpansionTile | إظهار بإرادة المختصة؛ لا واجهة طفل مستقلة |
| FR-112–114 (الحالة، الحكم، المساعدة، ملاحظات القراءة) | `models/assessment.dart`, `features/assessment_screen.dart` | مدخلات يدوية أولية |
| FR-115–116 (تصحيح وصفي لا تشخيصي) | `AssessmentScore`, `AssessmentSummaryScreen` | مطبق مبدئيًا؛ يحتاج تصديق سلم تقييم |
| FR-117 (استكمال المسودة) | `AppState`, `SecureLocalStore` | حفظ لكل بند؛ الحفظ التلقائي أثناء الكتابة لم يكتمل |
| FR-118–119 (اعتماد المختصة وعزل أداء الجلسات) | `AppState.approveAssessment` | اعتماد أولي؛ ربط الخطة لم يُنفّذ |
| FR-120 (إرسال ملخص مُجهّل معتمد فقط) | `ARCHITECTURE_AR.md` | غير منفذ؛ لا يوجد إرسال أو AI |
| FR-121–123 (عمل محلي مشفر، مزامنة، صلاحيات وسجل تدقيق) | `SecureLocalStore` جزئيًا | تخزين محلي فقط؛ المزامنة/RBAC/التاريخ مؤجلة |
| FR-125–128 (تطبيقان متكافئان Android/iOS) | Flutter + `scripts/bootstrap.*` | مصدر مشترك؛ لم يتم بناء/اختبار نسختي الأجهزة بعد |
| FR-35–64 (خطط وأنشطة وAI) | وثائق العمل المعمارية | غير منفذ |
| FR-65–73 (جلسات، دقة، رسوم) | `ARCHITECTURE_AR.md` | غير منفذ |
| FR-88–98 (Word/PDF وتقارير) | `WORK_PLAN_AR.md` | غير منفذ |

**تعريف حالة «تأسيسي»:** الكود متاح كنقطة بداية، لكنه لم يمر باختبارات توافق Android/iOS أو قبول تربوي رسمي بعد.
