# الخصوصية وسلامة استخدام الأطفال

## قواعد أساسية غير قابلة للتنازل

- لا حقول لاسم الطفل أو تاريخ الميلاد الكامل أو عنوانه أو رقم الهاتف أو تشخيص صحي/نفسي داخل التطبيق.
- يستخدم التقييم **الأعوام والأشهر** فقط لا تاريخ الميلاد.
- تجنّب معرفات مشتقة من اسم الطفل. يُفضّل رموز مولّدة عشوائيًا وتحتفظ المختصة بمطابقة الاسم والرمز خارج التطبيق في سجل آمن.
- لا صور أوراق الأطفال ولا تسجيلات صوتهم في MVP؛ الملاحظات تربوية وصفية فقط.
- لا استخدام لدرجات التقييم كتشخيص أو تصنيف صعوبات تعلم، ولا عتبات معيارية غير معتمدة.
- النتائج التي لم تُجرَ/تعذّرت ليست إجابات غير صحيحة، فلا تدخل في عدد الإجابات القابلة للتصحيح.
- التصحيح المهني والتعبير والإملاء بيد المختصة، والخطة المولدة مجرد مسودة لا تُنفذ دون اعتماد.
- قبل أي إرسال لنموذج AI: موافقة صالحة، صلاحية مستخدم، ملخص مُجهّل معتمد، معاينة إرسال، تقليل البيانات، وحذف النص الخام.

## فرق بين النموذج الأولي والإنتاج

**النموذج الحالي:** يخزن بيانات تجريبية محدودة مشفرة على الجهاز باستخدام تخزين نظام Android/iOS الآمن. لا يوجد اتصال بخادم ولا إرسال AI أو مزامنة. كما لا يوجد تسجيل دخول أو تفويض؛ لذا **ممنوع إدخال بيانات أطفال حقيقية في هذه النسخة**.

**قبل الإنتاج:**

- [ ] نص موافقة ولي الأمر/الإدارة صالح مع توثيق مصدر الموافقة وتاريخها.
- [ ] مراجعة سياسات الجهة التعليمية ومكان الاستضافة والعبور عبر الحدود.
- [ ] حسابات مستخدمين، MFA/رمز قفل وفق القرار، وصلاحيات على الخادم وتسجيل الاطلاع والتعديل.
- [ ] قاعدة بيانات مشفرة مناسبة ونسخ احتياطية واستعادة وخطة حذف/احتفاظ وتصدير آمن.
- [ ] فحص تسرب معلومات شخصية في الحقول الحرة واللوجات ورسائل الخطأ.
- [ ] عدم تخزين API keys في التطبيق، ونظام Rate Limits وإغلاق الوصول بعد الطلبات المخالفة.
- [ ] آلية تعارض مزامنة دون فقدان ومراجعة الأمن في Android/iOS.
- [ ] تدقيق آلية مشاركة الملفات والتقارير المجهلة والفصل بين الحسابات.
- [ ] اختبار على أجهزة حقيقية من النظامين؛ مراجعة سياسة المتاجر للبيانات الحساسة.

## Android / iOS

بعد توليد مجلد Android ينفذ bootstrap منع النسخ الاحتياطية التلقائية (`android:allowBackup="false"`) تجنبًا لفقد مفاتيح Keystore عند استعادة البيانات المشفرة على جهاز جديد. راجع إعدادات Keychain Sharing وحالات إغلاق التطبيق على iOS قبل الاختبارات. **التخزين الآمن على جهاز واحد ليس مزامنة ولا نسخة احتياطية موثوقة**.
