# تثبيت نسخة خطوة على Android

هذه نسخة تطوير ببيانات اصطناعية، بالإصدار `0.1.0+1` ومعرّف التطبيق `org.khotwa.khotwa`. نسخة `arm64-v8a` مخصصة لهواتف Android ذات المعالج 64 بت، ونسخة `armeabi-v7a` للأجهزة ذات المعالج ARM 32 بت، ونسخة `x86_64` للمحاكي المناسب. إذا لم تُعرف معمارية الهاتف، يمكن التحقق منها عبر `adb shell getprop ro.product.cpu.abi`. ملف APK الموحد من البناء السابق يتضمن المعماريات الثلاث.

يمكن نقل APK إلى الهاتف وفتحه لتثبيته، أو استخدام `adb install -r` مع مسار الملف المناسب. يُتحقق من توقيع التطوير باستخدام Android `apksigner` في مسار البناء، ويُرفق تقرير التوقيع ومعرّف البناء وSHA-256. هذا ليس توقيع نشر للمتجر أو دليل اختبار على هاتف فعلي.

## الاتصال بالخادم التجريبي

عنوان API المضمّن هو `http://127.0.0.1:3000`، ويحتاج الخادم المحلي العامل على هذا الكمبيوتر. لا يشير localhost على الهاتف إلى الكمبيوتر تلقائيًا. يلزم Android Platform Tools، وتفعيل تصحيح USB مؤقتًا في الهاتف والموافقة على اتصال الكمبيوتر، ثم:

```powershell
adb devices
adb reverse tcp:3000 tcp:3000
```

شغّل PostgreSQL وخادم المشروع كما يوضح README، ثم افتح التطبيق وأنشئ حساب تجربة. يجب أن يعود `/health` بحالة قاعدة بيانات جاهزة قبل اختبار الحسابات والمزامنة. عند فصل USB يتوقف الاتصال بالخادم؛ العمل المحلي بعد أول دخول يبقى مشفّرًا على الجهاز. يلزم إعادة إعداد الربط عند الحاجة. نجاح هذا المسار على جهاز فعلي ما زال غير متحقق.

يقتصر HTTP في نسخة Debug على loopback؛ لا تضع عنوان خادم عام غير مشفر. إصدار مستقل عن الكمبيوتر يحتاج خادم HTTPS معتمدًا وإعادة البناء بعنوانه. لا توجد خدمة إنتاج منشورة في هذا التسليم.

## نطاق هذه النسخة

الحسابات وملفات الطلاب المجهّلة وبطاقات التقييم ومسار مراجعة الخطط متاحة في الشريحة الحالية. بقية MVP وتوليد Gemini الحي والاختبار الميداني ما زالت كما يوضح `PROJECT_STATUS.md`. لا تستخدم بيانات طالب حقيقي. لا يوجد مفتاح AI داخل APK.
